JavaScript Events Workshop

A modular collection of interactive vanilla JavaScript DOM manipulation and event handling exercises.

  • Keyboard Image Gallery

    Display specific images based on numeric key presses (0-9) and clear the container when pressing any other key.

  • Movable Box

    Move a box across the screen by 10px in the specified direction using the keyboard arrow keys.

  • Interactive & Sortable List

    Dynamically add items via prompt input and remove items using a close button on each list item.

  • Dynamic Paragraph

    Append typed characters into a paragraph in real-time with a clear button to reset the content.

  • Evasive Box

    Prevent the mouse pointer from hovering over a box by randomly changing its screen position on mouseover.

  • Vowel Remover

    Remove all occurrences of a specific vowel from a text paragraph upon clicking its corresponding button.

  • Typing Speed Race

    A 2-player key-tapping speed test expanding two bars until one reaches 500px to announce the winner.

  • Memory Card Game

    A 6x5 grid color-matching memory game with drag-and-drop interaction, mismatch reset, and completion timer.
