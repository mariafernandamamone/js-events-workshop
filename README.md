# JavaScript Events Workshop

A modular, responsive web suite featuring interactive vanilla JavaScript exercises focused on DOM manipulation, keyboard listeners, mouse events, and dynamic UI updates. 

Built with a clean SASS architecture featuring a custom lilac & violet design system.

## 🛠️ Tech Stack & Architecture
* **Frontend Logic:** Vanilla JavaScript (ES6+)
* **Styling & Design System:** SASS / SCSS (Modular architecture using 7-1 pattern principles: variables, layout, landing, component modules)
* **HTML Structure:** HTML5 (Semantic & Accessible)
* **Version Control & Hosting:** Git, GitHub & GitHub Pages

## 📂 Project Structure
Each exercise lives inside its own isolated directory to maintain clean JS scope and CSS modularity:

* `scss/` & `css/` - Global SASS source files and compiled CSS stylesheet
* `01-keyboard-gallery/` - Keyboard Image Gallery (Numeric keypress listener 0-9)
* `02-movable-box/` - Movable Box (Arrow keys directional movement)
* `03-interactive-list/` - Interactive & Sortable List (Dynamic DOM insertion & removal)
* `04-dynamic-paragraph/` - Real-time Character Logger Paragraph
* `05-evasive-box/` - Evasive Box (Mouseover position randomization)
* `06-vowel-remover/` - Interactive Vowel Filter
* `07-typing-speed-race/` - Key Tapping Speed Challenge
* `08-memory-game/` - 6x5 Color Matching Pairs Game
